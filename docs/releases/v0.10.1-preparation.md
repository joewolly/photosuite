# v0.10.1 preparation

Status: **PASS — package cleanliness and release preparation**. No tag or release was created or published. The PR remains open for review and a future authorized v0.10.1 tag.

## Root cause and repair

Tauri's previous `frontendDist: "../src"` recursively embedded checked-out vendor submodules, including Git metadata, tests, CI configuration and development sources. Production now uses `../dist`, recreated by `beforeBuildCommand` for both `npm run build` and the workflow's `npx tauri build`.

`scripts/frontend-dist.mjs` follows the HTML script/style/icon roots, BINDB paths, static/dynamic module imports, literal worker URLs and `importScripts`. `scripts/frontend-runtime-assets.json` explicitly lists dynamic loader companions, runtime data, fonts, preset libraries, translations, bundled BiRefNet/SAM ONNX files, ONNX Runtime and other WASM, and licenses/notices. Vendor directories are never walked. Generated files retain their runtime paths. Existing app icon bytes and blur/median WASM have explicit aliases for already-requested URLs.

Every staging run removes old output after validating inputs, copies regular files in sorted order with fixed file permissions/timestamps and canonical LF text (binary bytes unchanged), then verifies the exact expected set and hashes. The verifier rejects unexpected directories/files, prohibited paths, symlinks, missing files and changed bytes. The model inventory allows only the three bundled selection ONNX files; external ComfyUI/Stable Diffusion/Real-ESRGAN weights are absent. `dist/` is ignored. Dev uses an explicit `../src` override. Upstream vendor contents and dependency versions are unchanged.

The package keeps PhotoSuite, `com.joewolly.photosuite`, and the existing unsigned distribution configuration. Version metadata is 0.10.1 in Tauri, Cargo.toml and the root Cargo.lock entry. The v0.10.0 tag must remain at `5a0155b0a7879dd7f726b8e50847038df6c3eb7c`, and its release remains draft.

## Inspection method

The [frontend inventory](v0.10.1-frontend-inventory.json) records every staged path, length and SHA-256: **711 files, 304,575,151 uncompressed bytes**, including three ONNX models and ten WASM binaries. Only runtime JavaScript from vendor `src`/`dist` directories is retained where directly referenced; the directories themselves are not recursively copied.

`scripts/inspect-packaged-frontend.py` reads the delivered executable's Tauri PHF asset table, translates Mach-O/PE/ELF virtual addresses to file offsets (resolving ELF relative relocations in an inspection-only copy), decompresses each Brotli payload and compares the entire table against this inventory. It checks both table boundaries, rejects missing/extra/changed assets, and checks Tauri-transformed HTML for all original runtime links and inline scripts. It does not infer package contents from build success or from a source-only manifest. The inspector was negatively controlled using an altered copy of the local executable: it rejected the renamed SAM encoder key and reported the missing and unexpected paths.

The inspector uses an isolated Python environment with **lief 1.0.0** and **brotli 1.2.0**; these are inspection tools, not application dependencies. Run it from the repository root after staging:

```sh
python scripts/inspect-packaged-frontend.py EXECUTABLE docs/releases/v0.10.1-frontend-inventory.json OUTPUT.json
```

Universal macOS executables are thinned with `lipo` and both slices inspected. Installer filesystem entries, package versions/architectures and loose licenses are inspected independently. NSIS helper binaries and Linux package control scripts are installer runtime infrastructure, not frontend vendor development files.
