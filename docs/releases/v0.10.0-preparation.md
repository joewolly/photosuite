## Signing and workflow

`bundle.macOS.signingIdentity` remains `null`. No signing identity, certificate, secret or notarization configuration was added. The unchanged build workflow guards Apple setup with `runner.os == 'macOS' && env.APPLE_CERTIFICATE != ''`; absent credentials skip signing/notarization setup and still build/upload the unsigned artifact. Windows has no signing configuration. The prior [hosted validation](../hosted-ci-validation.md) records unsigned installer builds. Branch/PR CI runs JavaScript and Rust checks; installer builds require a tag or manual dispatch, and the release job requires a tag. This pass triggers neither installer dispatch nor release publication.

Changing the bundle identifier intentionally separates the fork's application data from upstream, including plugins and saved settings. No automatic migration is introduced. The [plugin guide](../PLUGINS.md) gives current paths.
