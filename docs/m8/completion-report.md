3. **Implementation commits:** one bounded M8 implementation/evidence commit after local, real-backend and native acceptance. No squash/rewrite of M0–M7.
4. **Files added/modified:** [complete file manifest](changed-files.txt). New logic is concentrated in `expand-workload.js`, `expand-source.js`, `expand-target.js`, `exact-expand-tracker.js`, `expand-dialog.js`, and Rust `comfy/expand.rs`. Existing job/provider/menu/dispatch files receive narrow wiring; M6 Rust transport is factored for a fixed operation identity. Tests, corpus scripts, receipts, comparisons and documentation accompany it.
5. **Supported documents:** bounded RGB8 Normal raster layers, Normal/Pass Through groups, multiple/negative/off-canvas layer bounds, alpha, zero-feather raster masks and guides. Empty group markers from reopened PSD/PSB are supported. See [precise contract](README.md).
6. **Rejection policy:** reject unsupported geometry/structures before upload or inference; no hidden rasterization or approximation. Artboards, effects, adjustment/fill, clipping, knockout/channel overrides, special PSD Background layers, layer comps and linked assets are excluded, along with items below.
7. **Expansion geometry:** immutable `{width,height,left,top,right,bottom,newWidth,newHeight,exteriorPixels,byteLength}`; integer nonnegative additions, at least one pixel, checked dimensions/area/byte arithmetic.
8. **Coordinate translation:** old `(x,y)` maps exactly to `(x+left,y+top)`. One canonical record drives input, preview, containment and transaction. Existing `resizeDocumentCanvas` supplies translation on detached layers.
9. **Limits:** old/final axes ≤1024; final ≤1,048,576 pixels; each side ≤512; exterior ≤786,432 pixels; 64 raster/group entries; original raster/mask buffers ≤16 MiB; model ≤1024²; raw upload ≤5 MiB; one ≤4 MiB candidate; ≤4 MiB preview plus canvas; conservative session pixel sum ≤42 MiB. Separate snapshots/caches/transport/history are documented, not misrepresented as part of an RSS cap.
10. **Off-document preparation:** copied rendered composite placed at `(L,T)` without resizing; exterior and model padding use replicated edge context. Source layers, geometry and history remain untouched.
11. **Inference mask:** exterior generates; original interior is protected except the small inference-only overlap. Padding mask is zero. Expanded document coordinates and independent model padding are separate.
12. **Seam policy:** 16 pixels inside expanded edges may participate in inference. Editor authority accepts **zero** interior overlap. No hidden blend or repaint of source pixels.
13. **Containment proof:** result RGBA is zero throughout the original rectangle; exterior alpha is 255. Detached recomposition checks every protected byte before installation. Every real corpus case and native accepted fixture had zero changed bytes in the mapped old rectangle.
14. **Prompt:** reuse M6 validation and seed semantics, unchanged prompt text; empty prompt means contextual continuation. Optional unsigned 32-bit seed; bounded UTF-16/UTF-8 prompt.
15. **Backend/workflow/model:** existing numeric-loopback M2 transport; fixed `photosuite-generative-expand-v1`; reviewed built-in nine-node M6 graph; ComfyUI0.37.4 and unchanged `sd-v1-5-inpainting.ckpt`. Fresh checkpoint hash is in [acceptance](acceptance.md).
16. **M2/M6 reuse:** same upload/identity/graph/result validation, owned cancellation and native IPC/network stack; M6 prompt/seed/model graph logic. No arbitrary JSON workflows or parallel backend stack.
17. **Variations:** one sequential candidate. Expanded buffers and atomic snapshots justify a smaller budget than M6's patch candidates. No switcher or parallel generation.
18. **Preview:** independent bounded canvas in the job strip; cyan original-boundary outline, original/final dimensions and effective seed. Actual document geometry is unchanged until Accept; Discard and Cancel remove authority/state.
19. **Generated layer:** ordinary Normal full-expanded-canvas RGBA raster named `Generative Expand`; zero RGBA over original bounds, opaque exterior. Full rectangle is the reliable ordinary-layer representation for disjoint exterior strips; source imagery is not duplicated there.
20. **Atomic Accept:** revalidate exact source/context/history; bounded before snapshot; detached existing canvas translation; result insertion; protected projection verification; immutable after snapshot; preserve original live layer identities; install geometry/raster and one history item with postconditions; dispose transient state.
